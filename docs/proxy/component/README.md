# Proxy Components

This folder contains concise, focused how-to guides for the proxy-related features
exposed by EzFramework. Each file explains a single component with minimal code
examples to get started quickly.

Files:

- `messenger.md` — obtain and use the messenger on each platform
- `packet-registration.md` — how to register packet classes
- `channels.md` — default and custom channel usage
- `handler-registration.md` — registering and dispatching handlers
- `metrics.md` — collecting and reading messenger metrics
 - `retries-and-timeouts.md` — retries, timeouts and backoff
 - `error-handling.md` — handler and sender error handling
 - `serialization.md` — serializer usage and schema compatibility
 - `request-response.md` — request/response correlations and patterns
 - `bungee-empty-servers.md` — Bungee delivery notes for empty servers
 - `testing-and-debugging.md` — testing and debugging tips for messenger

Related: [overview.md](../overview.md)
