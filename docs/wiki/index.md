# Project Documentation

The public documentation is published and versioned on GitHub Pages. Each release is published under a path matching the release tag (for example `/1.0/`).

See [DOCS_INSTRUCTIONS.md](DOCS_INSTRUCTIONS.md) for guidance on authoring pages, previewing the site locally, and the publishing workflow.

You can view the public index at the site root once published (e.g., https://<owner>.github.io/<repo>/).
