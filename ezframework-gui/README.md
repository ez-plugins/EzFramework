# ezframework-gui

Concrete GUI implementation for EzFramework (Bukkit/Spigot).

This module provides `BukkitGuiService` which registers itself with the
core `EzGUI` accessor. It offers basic inventory menus and click handling.

See `ezframework-core` for the API: `com.skyblockexp.ezframework.gui.api`.
